# NM-v5.11

Telegram по умолчанию: чат `@nikamotors`, тема `message_thread_id=5`.
Переменные `TELEGRAM_CHAT_ID` и `TELEGRAM_MESSAGE_THREAD_ID`, если заданы, имеют приоритет.
Для публикации в тему бот должен быть добавлен в соответствующую группу/супергруппу и иметь право отправлять сообщения.


## Топливо в Telegram-публикации
Добавлена строка `⛽️ Топливо`. Значение нормализуется по явному полю Encar/XAPI (бензин, дизель, гибрид, газ, электро, водород). Если источник не распознаётся, исходный текст сохраняется для проверки; автоматическое значение по умолчанию не подставляется. В шаблоне публикации неизвестное значение отображается как «требует подтверждения».


## Исправление v5.12: распознавание гибридов
Если название, модель или комплектация конкретного объявления явно содержит Hybrid/HEV/하이브리드/«гибрид», итоговое топливо нормализуется как «Гибрид», даже если поле топлива Encar ошибочно сообщает бензин для гибридной силовой установки. Неизвестное топливо по-прежнему не угадывается.
